    三、怎么接线（STM32F103ZET6 ↔ AS5048A）

  AS5048A 是 TSSOP14 封装，数据手册 Figure 6 引脚定义如下：

  ┌──────────────┬────────────────────┬───────────────────────┐
  │ AS5048A 引脚 │        功能        │        接哪里         │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 1 CSn        │ 片选(低有效)       │ STM32 PA4             │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 2 CLK        │ SPI 时钟           │ STM32 PA5 (SPI1_SCK)  │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 3 MISO       │ 从机数据输出       │ STM32 PA6 (SPI1_MISO) │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 4 MOSI       │ 从机数据输入       │ STM32 PA7 (SPI1_MOSI) │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 5~10 TEST    │ 测试脚             │ 接 GND（或悬空）      │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 11 VDD5V     │ 供电 3.0~5.5V      │ 3.3V                  │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 12 VDD3V     │ 内部稳压 3.3V 输出 │ 3.3V（3V 供电模式）   │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 13 GND       │ 地                 │ GND                   │
  ├──────────────┼────────────────────┼───────────────────────┤
  │ 14 PWM       │ PWM 输出           │ 不用，悬空            │
  └──────────────┴────────────────────┴───────────────────────┘

  电源要点（重点看这里）：
  - 建议直接用 3.3V 供电：VDD5V 和 VDD3V 都接 3.3V（手册说 3V 供电时"VDD3V 短接到 VDD"），VDD5V 旁路一个 100nF 电容到
    GND。
  - 如果要用 5V 供电：VDD5V 接 5V，VDD3V 对地接 10µF 电容（不能当负载用）；但 5V 时 MISO 输出电平可能到 5V，STM32 的
    3.3V 引脚直连有风险。所以直接用 3.3V 供电最省事、电平完全匹配，不用电平转换。

  串口（看角度用）：
  - STM32 PA9 (USART1_TX) → USB 转串口模块 RX
  - STM32 PA10 (USART1_RX) → USB 转串口模块 TX
  - 波特率 115200，数据帧：0x55 0xAA [角度高字节] [角度低字节]

  别忘了磁铁： AS5048A 是磁编码器，芯片正上方必须放一个径向（直径方向）磁化的磁铁（常用 6×2.5mm），间距约
  0.5~2mm，磁场强度不能太弱也不能太强——太弱/太远时 bit14 会置 EF 错误标志（这正是建议你加校验的原因）。

对外接口：

  ┌────────────────────────────┬─────────────────────────────────────┐
  │            函数            │                作用                 │
  ├────────────────────────────┼─────────────────────────────────────┤
  │ AS5048A_Init()             │ 初始化（CS 置高）                   │
  ├────────────────────────────┼─────────────────────────────────────┤
  │ AS5048A_ReadAngle()        │ 读角度 + 校验，返回 {angle, status} │
  ├────────────────────────────┼─────────────────────────────────────┤
  │ AS5048A_ReadRegister(addr) │ 读任意寄存器原始 16 位帧            │
  ├────────────────────────────┼─────────────────────────────────────┤
  │ AS5048A_ReadMagnitude()    │ 读磁场强度 0~16383（判磁铁距离）    │
  ├────────────────────────────┼─────────────────────────────────────┤
  │ AS5048A_ReadAGC()          │ 读 AGC 0~255（255=磁场太弱）        │
  ├────────────────────────────┼─────────────────────────────────────┤
  │ AS5048A_ClearError()       │ 清错误标志                          │
  └────────────────────────────┴─────────────────────────────────────┘

  校验逻辑（核心）

  AS5048A_ReadAngle() 内部做了两层校验：

  1. 偶校验 PAR（bit15）—— 对整个 16 位帧做 XOR 归约，非偶数即 AS5048A_ERR_PARITY（此帧不可信）。
  2. 错误标志 EF（bit14）—— 芯片报告的传输错误，置位返回 AS5048A_ERR_EF。

  返回类型：
  typedef struct {
    uint16_t         angle;   // 14 位原始角度 0~16383
    AS5048A_Status_t status;  // OK / ERR_EF / ERR_PARITY
  } AS5048A_AngleResult_t;

  命令字和校验位不再硬编码，由 AS5048A_BuildCommand()
  自动算偶校验位，读任何寄存器都不会算错校验。读操作严格按手册的两帧流水线实现（发读命令 → 发 NOP 顶出数据），不再靠
  RX[3] 这种隐式下标。

  main.c 改动

  - 删掉了原来的 SPI_TX_DATA/RX_DATA、宏、op_num、post_process_value 等。
  - 主循环改用 AS5048A_ReadAngle()，出错时保持上一次有效角度，避免输出跳变。

  ⚠️ 注意：UART 帧的第二字节语义变了。新帧格式：

  0x55 | 状态字节 | 角度高字节 | 角度低字节

  状态字节：0xAA=正常、0xAB=EF 错误、0xAC=偶校验错。原来固定是 0xAA，上位机解析时需要按这个判断。

  你还需要做的

  1. 重新编译：Keil 里先 Rebuild（新文件 as5048a.c 已加入工程，但需要重新编译才会生效）。
  2. 上位机：角度 = (高字节<<8 | 低字节) × 360.0 / 16384.0，单位度；第二字节不等于 0xAA
     时说明这帧有错误（磁铁距离/磁场强度问题）。
  3. 磁铁：如果频繁出现 0xAB(EF)，多半是磁铁太远/太近/没对准，可以临时调用 AS5048A_ReadMagnitude()
     看幅值——正常应在中间量程（约几千），接近 0 或接近 16383 都说明磁场强度异常。

  接线方式和我上一轮说的完全一致，不需要改任何引脚（PA4=CS、PA5=SCK、PA6=MISO、PA7=MOSI）。需要的话我可以再帮你加一个滑
  动平均滤波，或把磁场强度一起塞进 UART 帧里。
